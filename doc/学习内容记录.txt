先看有哪些字段可用：

不给参数就是探测模式，等 6 秒列出所有字段名和当前值。实测你的程序发了 33 个字段。
然后组合：
# 单个变量
python D:\RM27_zimiao\rmplot\rmplot.py ekf_x

# 两个叠一个图（看跟随/对比关系）
python D:\RM27_zimiao\rmplot\rmplot.py gimbal_pitch,plan_pitch

# 三个图，每个叠两条
python D:\RM27_zimiao\rmplot\rmplot.py gimbal_yaw,plan_yaw gimbal_pitch,plan_pitch ekf_x,ekf_y

# 想看多少条都行
python D:\RM27_zimiao\rmplot\rmplot.py ekf_x,ekf_y,ekf_z
规则就一条：逗号连的进同一子图，空格分开的各占一个子图。子图之间 X 轴自动联动，时间对齐。
同组内颜色固定：第 1 条蓝、第 2 条红、第 3 条绿、第 4 条黄。所以习惯上把「实际值」写前面、「目标值」写后面，多次启动颜色不变，形成肌肉记忆。
其他参数：
# 保留更多历史（默认 1500 点，约 33 秒 @45Hz）
python D:\RM27_zimiao\rmplot\rmplot.py --window 5000 gimbal_yaw,plan_yaw

# 换端口
python D:\RM27_zimiao\rmplot\rmplot.py --port 45123 gimbal_yaw,plan_yaw

UDP 的特点是：
- 不需要等待对方确认；
- 不会因为某个丢失的数据包而阻塞后续数据；
- 延迟通常更低；
- 但可能丢包、乱序、重复，画面可能出现缺帧或花屏。
TCP 确实会：
- 按顺序传输；
- 检查数据有没有损坏；
- 丢包时自动重传；
- 尽量把数据可靠地交给对方。
